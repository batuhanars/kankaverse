# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

The SDK version is pinned to what the **Play Store build of Expo Go supports** (54), not to the newest
stable release. Do not bump it to chase a newer version: a project the store client cannot open is a
project the owner cannot test on a real phone. This constraint lifts only when dev builds land (M2).
